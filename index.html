📱 설치하기

두 가지 방식을 지원합니다. 사용 중인 디바이스에 맞춰 선택하세요.

iOS Safari 홈 화면 추가

  1. Safari 에서 https://jikjangin-a.example.com 접속
  2. 하단 공유 버튼 ⤴︎ 탭
  3. 스크롤 → 홈 화면에 추가
  4. 이름 확인 후 추가 → 홈 화면 아이콘으로 실행

iOS는 App Store 외 사이드로드를 허용하지 않습니다. PWA (Progressive Web App) 방식이 표준입니다.

Android 설치 옵션 두 가지

옵션 A — Chrome PWA 설치 (권장)

  1. Chrome 에서 https://jikjangin-a.example.com 접속
  2. 주소창 우측 설치 아이콘 또는 메뉴 → "앱 설치" 탭
  3. 홈 화면 아이콘으로 실행

옵션 B — APK 사이드로드 (TWA)

  1. 설정 → 보안 → "출처를 알 수 없는 앱" 또는 브라우저별 권한 허용
  2. 최신 APK 다운로드
  3. 다운로드된 .apk 파일 탭 → 설치

APK 는 Chrome 의 TWA(Trusted Web Activity) 래핑으로, 사실상 Chrome PWA 와 동일하지만 별도 앱 아이콘으로 보입니다.
