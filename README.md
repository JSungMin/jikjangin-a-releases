# 직장인A — 모바일 앱 릴리즈

> 월배당 ETF 투자 자동화 계산기 & 체크리스트 (Phase 1 MVP)
> **이 저장소는 소스 코드를 포함하지 않습니다.** 모바일 앱 다운로드 + 설치 안내 전용.

## 📥 최신 다운로드

[**Releases 탭**](https://github.com/JSungMin/jikjangin-a-releases/releases) 에서 가장 최근 `app-release-signed.apk` 를 받으세요.

## 📱 설치

### Android (APK 사이드로드)

1. APK 다운로드
2. 디바이스 설정 → 보안 → "출처를 알 수 없는 앱" 또는 브라우저별 권한 허용
3. 다운로드된 `.apk` 파일 탭 → 설치
4. 첫 실행 시 Google 로그인

### Android (Chrome PWA — 권장)

APK 없이도 Chrome 으로 운영 사이트에 접속 → 주소창 우측 설치 아이콘 또는 메뉴 → "앱 설치".

### iOS

Apple 정책상 사이드로드가 불가능합니다. Safari 로 운영 사이트에 접속 → 공유 → "홈 화면에 추가" → 홈 화면 아이콘으로 standalone 실행.
